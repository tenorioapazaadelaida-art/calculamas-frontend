# Calcula+: frontend para GitHub
Código local actual, incluidos los cambios pendientes. Extrae el ZIP y sube el contenido de la carpeta, incluyendo .gitignore y .env.example. No subas el ZIP como sustituto del código.
Se excluyeron historial Git, dependencias instaladas, compilaciones y configuración privada. Se conserva package-lock.json.
Instalación: npm ci; copiar .env.example a .env; ajustar VITE_API_URL; npm run dev. Compilación: npm run build. Usa una versión de Node compatible con package.json.
